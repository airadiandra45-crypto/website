# Norelle Frontend

Frontend starter untuk website Norelle berdasarkan desain yang diberikan di percakapan/Figma.

## Halaman
- Home
- Shop
- Wanita
- Pria
- Product Detail
- Search
- Shopping Cart
- Contact
- Profile

## Stack
HTML5, CSS3, JavaScript vanilla.

## Menjalankan
Bisa langsung membuka `index.html`, atau gunakan Live Server di VS Code.

## Upload ke GitHub
1. Buat repository baru, misalnya `norelle-frontend`.
2. Upload seluruh isi folder ini.
3. Commit dan push.
4. Jika ingin demo online, aktifkan GitHub Pages dari repository.

## Catatan
Asset gambar di folder `assets/images` adalah crop dari screenshot desain yang diberikan. Setelah asset final dari Figma tersedia, ganti file gambar tersebut dengan export final dari Figma tanpa perlu mengubah struktur HTML/CSS.
